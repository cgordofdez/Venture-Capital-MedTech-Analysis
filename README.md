# Venture-Capital-MedTech-Analysis
Análisis del ecosistema de Venture Capital en Biomedicina (66K+ registros). Pipeline en Python (Pandas/Matplotlib) y SQL para limpiar datos y extraer KPIs financieros (Ticket Medio, Tasa IPO). Proyecto orientado a la inteligencia de negocio y ventas corporativas B2B en MedTech, desarrollado con la visión de mercado de UAM Investments.
